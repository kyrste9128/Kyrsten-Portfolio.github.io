# Kyrsten Stewart Portfolio

## Overview

This is my personal portfolio website created for SDC355. It includes an About me section, Featured Content, Projects, and a Contact Form. The projects are stored using sessionStorage and displayed dynamically with JavaScript.

## Languages Used

- HTML
- CSS
- JavaScript

## Libraries

None

## Dependencies

No additional libraries are required.

## How to Run

Open the HTML file in a web browser or run it using a local web server such as XAMPP or Visual Studio Code Live Server.
